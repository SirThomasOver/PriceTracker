# PriceTracker
PT-BR
PriceTracker é um projeto em Python para monitorar preços de produtos em sites, verificar quando atingem um valor desejado e futuramente enviar alertas de promoção via WhatsApp. Projeto desenvolvido para praticar lógica de programação, requisições HTTP, tratamento de erros e automação.

EN-USA
PriceTracker is a Python project designed to monitor product prices on websites, detect when they reach a target price, and eventually send discount notifications via WhatsApp. This project was developed to practice programming logic, HTTP requests, error handling, and automation.
